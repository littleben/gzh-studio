# Markdown 写法速查

## frontmatter

```yaml
---
title: 标题（最多 64 字）
cover: ./images/cover.png      # 封面，会被裁成 2.35:1
theme: latepost                # latepost emerald ocean graphite olive zen
author: 作者名                  # 可选
digest: 摘要                    # 可选，默认取第一段前 110 字
cta: 页脚引导语                  # 可选，空字符串表示不要
---
```

正文第一张图写 `![封面](./images/cover.png)` 时，渲染会跳过它（封面只用在卡片上）。

## 行内

| 写法 | 效果 |
|---|---|
| `**文字**` | 主色加粗（graphite/olive/zen 是深色加粗） |
| `++文字++` | 下划线 |
| `==文字==` | 浅底色高亮标签 |
| `` `code` `` | 行内代码 |
| `[文字](链接)` | 只保留文字（公众号正文不支持外链） |

## 块

| 写法 | 组件 |
|---|---|
| 第一段 | 导语（大一号、半粗） |
| `## 一、标题` | 章节标题，自动编号 01/02，「一、」会去掉 |
| `### 标题` | 小节标题（左竖条 + 浅底） |
| `1. ` 列表 | 主色圆形数字 |
| `- ` 列表 | 主色圆点 |
| ```` ```bash ```` | 深色代码块，带三色圆点和语言名 |
| `![说明](图)` | 白底卡片图 + 「— 说明」图注 |
| Markdown 表格 | 主色表头 + 斑马纹 |
| `> 一句话` | 居中金句（上下细线） |
| `> **标题**` + 多行 | 黑框引用卡（底部主色线） |
| `---` | 居中分隔 |
| `**关于作者**` + 若干行（放在最后） | 页脚 |

## 组件（`> [!TYPE]`）

```markdown
> [!INTRO] 核心判断，用 ==关键词== 点题。          开头引言卡，关键词变成主色底白字

> [!TOC] 看点一 | 看点二 | 看点三                   本文看点，最多 3 个

> [!DATA] 9.5 万 | 网站用户                         数据卡片，2～3 行
> 65% | 新关注来自扫码

> [!TIMELINE] 10 月 3 日 | 第一版上线               时间线，每行「标题 | 内容」
> 10 月 7 日 | 改成配对码

> [!PILLS] 默认：配对码 | 一句话说明               胶囊要点列表，每行「标题 | 说明」

> [!QUOTE] 读者最该记住的一句话。                   左竖条 + 浅底的金句

> [!NOTE] 口径、来源、补充说明。                    灰色旁注

> [!WARN] 一句话的踩坑结论。                        「！踩坑提示」

> [!TIP] 给照做的人的提醒。                         主色提示条

> [!END]                                            END 分割线
```

`<!-- 注释 -->` 会在渲染时去掉，可以写给自己看的备注。
